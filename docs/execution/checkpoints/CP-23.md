Data: 2026-10-25 (America/Recife).

- Branch `codex/wave-23-inbox-pagination`, base onda 22 (`718434f`).

- APIs mantêm nextCursor, aceitam cursor legado ISO e usam novo cursor opaco com escopo, timestamp e ID. Limites inválidos retornam 422.
